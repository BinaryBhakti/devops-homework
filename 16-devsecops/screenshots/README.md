## Two kinds of image

**Local runs (`0N-*.png`)** are **renders of the captured transcripts**, not screen captures
of a live terminal. The labs were run non-interactively from scripts, so there was no terminal
window to photograph. The subtitle bar in each image names the exact file in
[`../outputs/`](../outputs) it was produced from. Every character is verbatim output from a
command that actually ran. The transcript was laid out as HTML and photographed with headless
Chrome (`deviceScaleFactor: 2`, so the text is legible at full size).

**Pipeline runs (`gh-*.png`)** are headless-Chrome captures of the real GitHub Actions pages
for the runs linked in the README.

## If your submission needs conventional screenshots

Re-run the commands from the write-up in your own terminal and replace these files, keeping
the names. The inline references in `../README.md` will then point at your captures.
