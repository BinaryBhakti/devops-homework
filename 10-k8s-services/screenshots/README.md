# Screenshots

Empty on purpose.

The course submission format asks for a screenshot per task. Everything in this homework was
run non-interactively, so instead of screenshots the evidence is the **verbatim transcripts**
in `../outputs/` — every command and every byte of its output, captured as it ran. Each
`console` block in the write-up is a copy out of those files, so the two can be diffed against
each other.

If you need screenshots for the Google Form submission, re-run the commands from the write-up
in your own terminal and drop the images here. The filenames the lab sheet asks for are listed
per task in the main README.
