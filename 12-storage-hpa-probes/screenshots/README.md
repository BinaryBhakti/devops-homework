## What these are

Every lab in this homework was run **non-interactively**, from scripts, so there was no GUI
terminal window to photograph. Each image is therefore a **render of the captured transcript**,
not a screen capture of a live session — the subtitle bar in every image names the exact file
in [`../outputs/`](../outputs) it was produced from.

The content is real. Every character is verbatim output from a command that actually ran
against the cluster, taken straight from the committed transcript. What differs from a
conventional screenshot is only how the pixels were produced: the transcript was laid out as
HTML and photographed with headless Chrome. Where an image shows two separate excerpts of a
transcript, they are separated by a blank line.

Renderer: device scale factor 2, so the text is legible at full size.

## If your submission needs conventional screenshots

Re-run the commands from the write-up in your own terminal and replace these files, keeping the
names — the inline references in `../README.md` will then point at your captures. Every command
is shown in the write-up, and the transcripts give the expected output to check against.
