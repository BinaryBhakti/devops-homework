# register the app: Git repo + path = desired state, this cluster + namespace = destination
$ cat argocd-application.yaml
# Applied once, by hand, from an admin shell. It lives OUTSIDE app/ on purpose: Argo CD
# watches app/, and an Application that manages itself is a different (app-of-apps) pattern.
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: gitops-demo
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/BinaryBhakti/devops-homework.git
    targetRevision: main
    path: 19-monitoring-observability-gitops/03-gitops/app
  destination:
    server: https://kubernetes.default.svc
    namespace: session20
  syncPolicy:
    automated:
      prune: true        # delete what was removed from Git
      selfHeal: true     # undo changes made outside Git
    syncOptions:
      - CreateNamespace=true

# what was found, in order (each step is in the session notes behind this homework):
#  1. repo-server log: "Could not resolve host: github.com" — intermittent; CoreDNS forwards to Docker Desktop DNS (192.168.65.254), which dropped queries when the host was under load
#  2. with DNS fine: "rpc error: code = DeadlineExceeded" — the controller allows the repo-server 60 s per manifest request, git commands 90 s
#  3. a manual clone inside the repo-server: "fetch-pack: unexpected disconnect while reading sideband packet" after ~120 s
#  4. the cause under it all: this link downloads at ~0.5 MB/s, and the homework repo is ~70 MB of screenshots. A full clone cannot finish in time.
