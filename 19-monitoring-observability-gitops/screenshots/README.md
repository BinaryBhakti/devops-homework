# Screenshots — Homework 19 (Session 20)

17 images, referenced inline from [../README.md](../README.md).

## Two kinds of image

**Real browser screenshots (01–09).** Grafana, Prometheus, Alertmanager, Jaeger and the Argo CD
UI were photographed with headless Chrome while the stack and the cluster were running. The
monitoring ones (01–06) were taken while the alerts in Task 1 were firing.

**Transcript renders (10–17).** The terminal labs ran non-interactively from scripts, so there
was no terminal window to photograph. Each of these is a render of the captured transcript: the
subtitle bar names the exact file in [`../outputs/`](../outputs) it was produced from, and every
character is verbatim output from a command that actually ran.

Renderer: device scale factor 2, so the text is legible at full size.

## If your submission needs conventional screenshots

Re-run the commands from the write-up in your own terminal and replace these files, keeping the
names — the inline references in `../README.md` will then point at your captures.
