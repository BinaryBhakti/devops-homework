# macOS ships LibreSSL, whose `openssl x509` has no -ext flag (the usage dump it printed
# has been replaced here with the equivalent that does work):

# the lab-sheet openssl command has no -addext subjectAltName, so the cert carries NO SANs.
# Go's crypto/x509 (which ingress-nginx uses) ignores Common Name entirely since Go 1.15,
# so a cert with no SAN matches no hostname at all and the controller falls back to its own.
# regenerate with SANs for both hosts:
